# Theseus Standard Toolset Proposal (기본 툴셋 구성 제안)

**작성일**: 2026-04-27
**작성자**: Antigravity AI
**문서 목적**: Theseus B2B 에이전트 플랫폼이 기본적으로 갖추어야 할 핵심 도구(Standard Toolset) 목록을 정의하고, 각 도구의 역할 및 권한 레벨(RBAC) 가이드라인을 제시합니다.

---

## 1. 🛠️ 플랫폼 코어 (Core Platform)
에이전트의 자율적 운영과 확장을 지원하는 핵심 도구입니다.

| 도구명 | 설명 | 권한 레벨 | 상태 |
| :--- | :--- | :---: | :--- |
| `create_tool` | LLM이 직접 파이썬 코드를 작성하고 검증하여 새로운 도구를 생성 및 등록 | 3 | 구현 완료 |
| `StructuredPlanner` | 복잡한 작업을 단계별 계획(Plan)으로 분리하여 승인 후 실행하는 시스템 로직 | - | 내장됨 |
| `ToolValidator` | 생성된 코드의 보안 및 규격 준수 여부를 AST 분석으로 자동 검증 | - | 내장됨 |

## 2. 📁 인프라 및 시스템 제어 (Infrastructure)
격리된 샌드박스 내에서 파일 및 시스템을 제어하는 도구입니다 (OpenHarness 기반).

| 도구명 | 설명 | 권한 레벨 | 비고 |
| :--- | :--- | :---: | :--- |
| `bash` / `powershell` | 시스템 셸 명령어 실행 및 결과 확인 | 3 | 격리 환경 필수 |
| `read_file` | 특정 경로의 파일 내용을 읽어옴 | 1 | |
| `write_file` / `edit_file` | 파일 생성, 덮어쓰기 또는 특정 블록 수정 | 2 | |
| `glob` / `grep` | 패턴 매칭을 통한 파일 목록 탐색 및 내용 검색 | 1 | |

## 3. 🧠 지식 및 컨텍스트 (Knowledge & Context)
엔터프라이즈의 방대한 지식과 현재 세션의 맥락을 연결하는 도구입니다.

| 도구명 | 설명 | 권한 레벨 | 비고 |
| :--- | :--- | :---: | :--- |
| `search_knowledge_base` | Vector DB(ChromaDB)와 연동된 사내 지식 베이스 검색 (RAG) | 1 | 로드맵 상 필수 |
| `get_session_info` | 현재 유저 ID, 프로젝트 권한, 잔여 토큰 쿼타 등 메타데이터 조회 | 1 | 신규 제안 |
| `manage_memory` | 태스크 수행 중 필요한 핵심 정보를 Key-Value 형태로 임시 저장 및 인출 | 1 | 신규 제안 |

## 4. 🛡️ 거버넌스 및 안전 (Governance & Safety)
B2B 환경에서 에이전트의 행동을 통제하고 투명성을 확보하는 도구입니다.

| 도구명 | 설명 | 권한 레벨 | 비고 |
| :--- | :--- | :---: | :--- |
| `request_human_approval` | 민감한 액션 수행 전, UI를 통해 관리자의 명시적 승인을 요청 | 1 | HITL 강화 |
| `audit_log_report` | 에이전트가 수행한 주요 의사결정과 액션을 시스템 로그에 기록 | 1 | 투명성 확보 |
| `validate_security` | `ToolValidator`를 노출하여 에이전트가 코드 생성 전 스스로 검증하도록 지원 | 2 | 자가 디버깅 |

## 5. 🔌 엔터프라이즈 연동 (Enterprise Integration)
사내 레거시 시스템 및 유틸리티와의 안전한 연동을 지원합니다.

| 도구명 | 설명 | 권한 레벨 | 비고 |
| :--- | :--- | :---: | :--- |
| `internal_api_call` | 사전 승인된 내부망 API 리스트에 대해 보안 헤더를 포함하여 요청 | 2 | 게이트웨이 역할 |
| `json_to_markdown` | 복잡한 데이터 구조(JSON)를 사용자 보고용 테이블/차트로 변환 | 1 | 유틸리티 |
| `query_enterprise_db` | 제한된 뷰(View)나 전용 ORM을 통해 사내 DB 데이터 조회 | 2 | 읽기 전용 권장 |

## 🚀 향후 로드맵 반영 권고사항

1. **Tool RAG (Dynamic Loading)**
   - 등록된 도구가 50개를 넘어갈 경우, 매 턴 모든 명세를 전달하는 대신 질문 의도에 맞는 **상위 10개 내외의 도구만 동적 로드**하는 기능을 Standard Toolset의 일부로 포함해야 합니다.

2. **Sandbox Environment Enforcement**
   - 위 목록 중 레벨 2 이상의 도구(시스템 수정, API 호출 등)는 반드시 **물리적으로 격리된 샌드박스 컨테이너**에서만 실행되도록 아키텍처 수준에서 강제해야 합니다.

3. **Quota & Billing Integration**
   - 모든 도구 호출 직후 발생한 비용(Token Usage)을 과금 엔진으로 즉시 전송하는 기능을 도구 실행 파이프라인에 내재화해야 합니다.

## 6. 🤖 추가 보완 제안 (Theseus AI Agent 분석 결과)

**작성자**: Theseus AI Agent
**작성일**: 2026-04-27
**추가 목적**: Antigravity AI가 제안한 초기 툴셋을 바탕으로, 실제 에이전트 구동 과정에서 발생할 수 있는 모호성 해결 및 사용자 경험(UX) 강화를 위해 필수적인 코어 도구들을 추가 제안합니다.

### 6.1. 추가 제안 도구 목록

| 도구명 | 설명 | 권한 레벨 | 추가 사유 및 비고 |
| :--- | :--- | :---: | :--- |
| `ask_user_question` | 작업 목표가 모호하거나 추가 파라미터가 필요할 때, 사용자에게 객관식/주관식 질문을 던지고 답변을 대기 | 1 | **환각(Hallucination) 방지용 최우선 도구**. `request_human_approval`이 단순 결재(O/X)라면, 이 도구는 양방향 소통을 위한 필수 인터페이스입니다. |
| `send_notification` | 장기 실행(Long-running) 작업 완료, 혹은 치명적 에러 발생 시 사내 메신저(Slack, Teams 등)로 비동기 알림 전송 | 1 | 에이전트가 백그라운드 태스크로 동작할 때 사용자 편의성 증대. |
| `rollback_state` | 특정 작업(파일 수정, DB 트랜잭션 등) 실패 시, 시스템을 이전 상태(Checkpoint)로 되돌림 | 3 | 엔터프라이즈 환경에서 "안전한 실패(Fail-safe)"를 보장하기 위한 코어 롤백 메커니즘. |

### 6.2. 기존 도구 스펙 강화 권고사항

*   **`query_enterprise_db` 안전장치 강제화**: 해당 도구는 프롬프트 지시와 무관하게 시스템 레벨(SQL Parser)에서 `SELECT` 문장만 실행되도록 원천 차단 로직이 결합되어야 합니다. (예: `DROP`, `DELETE`, `UPDATE` 쿼리 입력 시 즉시 Security Violation 반환)
*   **권한 레벨 동적 승격 (Privilege Escalation)**: 평소에는 Level 1, 2 도구만 노출하다가, 특정 작업을 위해 Level 3(예: `bash`)가 필요할 경우 사용자에게 OTP나 2FA 승인을 받아 일시적으로 권한을 격상시키는 워크플로우 도입을 제안합니다.
